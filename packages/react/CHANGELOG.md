# Changelog

Changes to `@coffeejson/react`. Changes to the format itself are in the
[root changelog](https://github.com/coffeejson-org/coffeejson/blob/main/CHANGELOG.md).

## [1.1.0] — 2026-09-11

### Changed

- The package depends on `@coffeejson/core` `^1.1.0`. Cards show gear as
  core's `gearLabel` renders it: the registry label for a known id, with
  `variant` beside it.
- The components have no behavior change of their own.
